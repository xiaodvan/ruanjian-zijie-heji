## 关于本仓库（技术说明）

安装包体积较大，如果直接提交进 Git 仓库，会让仓库体积**永久膨胀**、`git clone` 越来越慢（历史上传的大文件即使删掉也仍留在 Git 历史中）。放进 Release 附件则没有这些问题：

- 单个附件最大 **2 GB**
- **不计入**仓库体积
- 点一下就能下载，无需先 clone 仓库

### 如何发布新版本

```bash
gh release create v1.0.0 "./YourApp-1.0.0.apk" \
  --title "YourApp 1.0.0" \
  --notes-file RELEASE_NOTES.md
```
